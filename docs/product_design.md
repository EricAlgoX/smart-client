# Smart-Client 通版产品设计

## 一、产品定位

**一句话**：开箱即用的 AI 视频分析终端，面向物业管理、园区安防、工地监管等小B客户。

**卖点**：
- 客户拿到就能用，不需要技术背景
- 接一个摄像头就能跑，实时看结果
- 算法可插拔——同一个软件，换个模型就是不同产品

---

## 二、典型客户场景

| 客户 | 核心需求 | 算法 | 客户最关心的 |
|------|---------|------|------------|
| 物业小区 | 车牌识别、违停检测 | 车牌+车辆 | 能不能自动识别、能不能截图留证 |
| 园区/工厂 | 区域入侵、人员闯入 | 人+围栏 | 准不准、误报多不多 |
| 工地 | 安全帽检测、渣土车 | 安全帽+车辆 | 有没有违规、能不能导出报表 |
| 商场/写字楼 | 人群聚集、火灾烟雾 | 人+火+烟 | 安全预警、实时通知 |

**关键洞察**：客户不关心"模型"、"NMS"、"置信度"这些术语。他们关心的是：
1. 我的摄像头能不能接上？
2. 准不准？
3. 出了事能不能查到记录？

## 三、界面重新设计

### 设计原则
1. **傻瓜式操作**：3 步完成——接源、选场景、开始
2. **结果导向**：重点展示检测结果和历史记录，不是参数调节
3. **专业感**：深色主题、大画面、信息密度适中
4. **可演示**：打开就能跑 demo，方便销售现场演示

### 核心变化（对比现有）

| 维度 | 现在 | 目标 |
|------|------|------|
| 左侧面板 | 源管理树+参数调节 | **去掉**，参数收入"设置"弹窗 |
| 场景选择 | 下拉选模型（30+英文名） | **场景卡片**：车牌识别/区域入侵/安全帽检测 |
| 视频区 | 单画面 | 单画面（通版足够），留双画面扩展 |
| 右侧面板 | 检测结果表格+统计 | **实时告警流** + 统计卡片 |
| 底部表格 | 检测结果（类别/置信度/坐标） | **检测记录**（时间/类型/详情/截图） |
| 参数调节 | 直接暴露在左侧 | 收入**设置弹窗**，客户不需要看到 |
| ROI围栏 | 手动画多边形 | 保留，但在"设置"里 |
| 数据导出 | 一键保存 | 改为**自动记录** + 手动导出 |

## 四、功能模块重定义

### 4.1 场景模式（替代"模型选择"）

客户不选"模型"，选"场景"：

```
┌──────────────────────────────────────┐
│         选择检测场景                   │
│                                      │
│  ┌──────────┐  ┌──────────┐         │
│  │ 🚗       │  │ 🚶       │         │
│  │ 车牌识别  │  │ 区域入侵  │         │
│  │ 车辆检测  │  │ 人员检测  │         │
│  └──────────┘  └──────────┘         │
│  ┌──────────┐  ┌──────────┐         │
│  │ 🔥       │  │ 🏗️       │         │
│  │ 安全检测  │  │ 工地监管  │         │
│  │ 火灾烟雾  │  │ 安全帽   │         │
│  └──────────┘  └──────────┘         │
└──────────────────────────────────────┘
```

每个场景背后绑定一组算法（1~3个模型组合），前端不暴露模型细节。

### 4.2 视频源接入

保留 2 种方式：
1. **摄像头**：输入 IP 地址，一键连接（实际部署用）
2. **图片**：选择本地图片（演示测试用，方便销售现场展示效果）

去掉"文件夹"和"视频"——开发测试用的功能，不是客户场景。

### 4.3 实时告警流（替代"检测结果表格"）

```
14:32:01  🟡 车牌识别  鲁B·12345  驶入A区     [查看]
14:31:58  🔴 区域入侵  人员进入B区围栏         [查看]
14:31:45  🟢 安全帽    检测到3人未佩戴         [查看]
14:31:30  🟡 车牌识别  鲁B·67890  驶出A区     [查看]
```

- 颜色区分级别：🟢正常 🟡注意 🔴告警
- 点击"查看"可回看该帧截图
- 自动滚动，最新在上

### 4.4 检测记录（替代底部表格）

```
┌─────────────────────────────────────────────────────────┐
│ 时间        │ 类型     │ 详情              │ 截图 │ 导出 │
├─────────────┼──────────┼───────────────────┼──────┼──────┤
│ 14:32:01    │ 车牌识别  │ 鲁B·12345        │ [📷] │      │
│ 14:31:58    │ 区域入侵  │ 人员进入B区       │ [📷] │      │
│ 14:31:45    │ 安全帽    │ 3人未佩戴         │ [📷] │      │
│             │          │                   │      │ [导出]│
└─────────────────────────────────────────────────────────┘
```

- 自动记录所有检测结果
- 支持按时间/类型筛选
- 底部有"导出今日记录"按钮

### 4.5 设置弹窗（替代左侧参数面板）

客户不需要日常调参数，但需要：
- 接入新摄像头
- 调整检测区域（ROI）
- 设置告警灵敏度（简单的 高/中/低，不是 NMS 滑块）
- 导出数据

## 五、技术实现要点

### 5.1 不需要改的（保持现有）
- `core/client.py` — HTTP 推理客户端
- `core/stream.py` — 视频流读取
- `core/converter.py` — 图像格式转换
- `core/writer.py` — 数据保存
- `core/server.py` — 算法服务管理
- `utils/*` — 工具函数

### 5.2 需要重写的
- `app.py` — 主界面（新布局）
- `controller/main_controller.py` — 业务逻辑（场景切换、告警流、记录管理）
- `resources/style.qss` — 样式表

### 5.3 需要新增的
- 场景配置文件（`scenes.json`）：每个场景绑定哪些模型
- 告警规则（简单版）：什么结果算告警
- 检测记录管理：自动保存、查询、导出

## 六、开发优先级

### P0 — 通版 MVP（必须有）
1. 场景选择界面（卡片式）
2. 视频源接入（摄像头 IP + 本地视频）
3. 实时视频显示 + 检测框
4. 实时告警流
5. 检测记录表
6. 状态栏
7. 深色工业主题

### P1 — 增强体验
1. 设置弹窗（灵敏度高/中/低）
2. ROI 围栏设置
3. 记录导出（CSV/截图）
4. 告警截图自动保存

### P2 — 可选扩展
1. 多摄像头切换
2. 告警声音提示
3. 历史记录回看
4. 日报/周报自动生成
