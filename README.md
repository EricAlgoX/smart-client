# Smart-Client

基于 PySide6 的 AI 视觉智能分析客户端，支持多种输入源和 30+ 种算法模型的实时检测与识别。

## 功能特点

- **多源输入**：支持图片、视频、文件夹批量处理、RTSP/HTTP 视频流、本地摄像头
- **丰富算法**：集成 30+ 种 AI 检测/识别算法（行人、车辆、渣土车、车牌、人脸、火灾、烟雾等）
- **实时预览**：视频画面实时显示检测结果，带检测框和类别标注
- **ROI 围栏**：支持在画面上绘制多边形感兴趣区域，限定检测范围
- **参数调节**：可调节 NMS 重叠度、置信度阈值、超时时间
- **数据导出**：一键保存当前帧（图片）和检测结果（VOC XML 格式）
- **性能监控**：内置性能分析工具，实时监控各环节耗时
- **动态界面**：半透明深色主题 + 漂浮圆点动画背景

## 使用说明

1. **选择输入源**：点击「图片」「视频」「文件夹」或「视频源」按钮加载数据
2. **选择模型**：在下拉框中选择需要的 AI 算法模型
3. **调节参数**：根据需要调整 NMS、置信度等参数
4. **设置围栏**（可选）：点击「设置围栏」在画面上绘制 ROI 多边形区域
5. **开始推理**：点击「开始推理」启动检测，实时查看结果
6. **保存数据**：点击「保存数据」导出当前帧和检测标注

## 项目结构

```
smart-client/
├── app.py                      # 程序入口，主窗口和动画效果
├── info.py                     # 应用信息（名称、版本、仓库地址）
├── api.json                    # 算法 API 接口配置
├── requirements.txt            # Python 依赖
├── controller/
│   └── main_controller.py      # 业务逻辑控制层（事件绑定、数据流转）
├── core/
│   ├── client.py               # HTTP API 客户端（图像编码、推理请求、结果解析）
│   ├── converter.py            # 图像格式转换（BGR→RGB→QImage，异步线程）
│   ├── queue.py                # 全局消息队列（图像队列、结果队列）
│   ├── server.py               # 算法子进程管理（启动/停止 FastAPI 服务）
│   ├── stream.py               # 数据源抽象（图片、视频、文件夹、实时流）
│   ├── visualizer.py           # 检测框绘制（支持中文字体）
│   └── writer.py               # 异步数据保存（图片 + VOC XML 标注）
├── ui/
│   └── mainwindow.ui           # Qt Designer 界面文件
├── utils/
│   ├── general.py              # 通用工具（渐变文字、系统信息采集）
│   ├── logger.py               # 彩色日志（单例模式）
│   └── profiler.py             # 性能分析工具（装饰器自动计时）
└── resources/
    ├── app.ico                 # 应用图标
    ├── demo.png                # 界面截图
    ├── icons/                  # 背景图片
    └── reference/              # 参考图片
```

## 架构说明

```
┌─────────────┐    ┌──────────────┐    ┌─────────────┐
│  数据源      │───▶│  图像队列     │───▶│  API 客户端  │
│ (stream.py) │    │ (queue.py)   │    │ (client.py) │
└─────────────┘    └──────────────┘    └──────┬──────┘
                                              │ HTTP POST
                                              ▼
┌─────────────┐    ┌──────────────┐    ┌─────────────┐
│  UI 显示     │◀──▶│  格式转换     │◀───│  结果队列    │
│(controller) │    │(converter.py)│    │ (queue.py)  │
└─────────────┘    └──────────────┘    └─────────────┘
```

- **数据流**：数据源 → 图像队列 → API 客户端（HTTP 推理）→ 结果队列 → 格式转换 → UI 显示
- **多线程**：API 请求、图像转换、数据保存均在独立线程中异步执行，不阻塞 UI
- **子进程**：算法服务通过 `server.py` 以子进程方式启动 FastAPI，按需启停
