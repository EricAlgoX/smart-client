Welcome to the **Claude Autonomous UI Architect Skill** repository. This project provides a comprehensive operational framework—often called a "Skill Context" or "System Prompt"—that transforms Claude AI into an elite, autonomous front-end engineering lead and UI/UX designer.

## 📖 The Vision
The landscape of software development has shifted from manual coding to **agent-driven execution**. This repository gives Claude the contextual "institutional memory" required to act strictly as a Senior Engineer. By loading this skill, Claude abandons generic "AI code generation" habits and adopts rigid, scalable, component-driven development principles.

## 📂 Repository Structure

- `SKILL.md`: The core directive system prompt. Feed this directly to Claude.
- `STANDARDS.md`: Deep dive into the Tailwind, CSS, and Shadcn UI requirements.
- `EXAMPLES.md`: Reference input/output standards showing architecture & aesthetics.
- `TRENDS_2026.md`: The latest state-of-the-art UI/UX patterns (Hyper-personalization, Neo-Brutalism, Generative UI).
- `MOTION.md`: Advanced physics-based animation rules (Framer Motion, Springs vs Tweens).
- `ACCESSIBILITY.md`: Strict WCAG 2.2 criteria, Semantic HTML, and SR-Only mappings.
- `QA_WORKFLOW.md`: The step-by-step 5-checkpoint analytical loop Claude runs before responding.
- `PROMPT.txt`: A simple, raw copy-paste version of the entire skill for immediate use.

## 🛠️ How to Use This Skill

### Option 1: AI IDEs (Google Antigravity, Cursor, Windsurf)
1. Clone this repository into your project's local agent folder (e.g., `.agent/skills/autonomous_ui_architect/`).
2. The agent will automatically parse the `SKILL.md` file using its YAML frontmatter.
3. Watch as Claude autonomously researches references and implements pixel-perfect designs.

### Option 2: Claude Web/Desktop App (Projects Feature)
1. Create a new "Project" in Claude.
2. Upload the `.md` knowledge files into the Project Knowledge base.
3. In the Custom Instructions, write: *"You are to strictly abide by the rules and directives outlined in the uploaded `SKILL.md` and `STANDARDS.md` files."*

## 🌟 What Makes This Skill Different?

1. **Anti-Bloat Directive:** Prohibits Claude from generating monolithic screen files. Enforces a strict Primitives → Abstractions → Blocks hierarchy.
2. **Modern Aesthetics (2026 Standards):** Demands the use of micro-interactions, logical properties for RTL support, and high-fidelity typography.
3. **The Validation Loop:** Injects a "Run-Fix-Repeat" QA loop directly into Claude's reasoning process, ensuring code isn't just generated, but algorithmically verified before output.
4. **No "Gray Boxes":** Eliminates the dreaded visual placeholder syndrome.
