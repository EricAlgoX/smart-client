# Industrial Vision UI Skill

When designing pages:

Layout:

Top:

* Menu Bar
* Toolbar

Left:

* Navigation Tree

Center:

* Video Area

Right:

* Detection Results
* Statistics

Bottom:

* Logs

Use QSplitter.

Support multi-monitor deployment.

Support 1920x1080 minimum.

Support 4K scaling.

Provide dark theme by default.

UI should resemble industrial monitoring software.

Avoid toy-like interfaces.
