# 动效与交互

## PySide6 能做的

| 效果 | 方式 | 成本 |
|------|------|------|
| 按钮 hover/pressed 变色 | QSS 伪状态 | 零 |
| 焦点环 | QSS `:focus-visible` | 零 |
| 面板顶部强调色条 | QSS `border-top` | 零 |
| 连接指示灯变色 | `setObjectName` + `style().unpolish/polish` | 零 |
| 漂浮粒子背景 | `QTimer` + `QPainter` 自绘 | 低 |
| 骨架屏 shimmer | QSS 渐变背景 | 零 |

## PySide6 做不了的

- ❌ CSS transition 动画（QSS 不支持）
- ❌ 弹性/物理动画（需要 QPropertyAnimation，复杂）
- ❌ 滚动触发动画
- ❌ 鼠标跟随光效

## 原则

**只做 QSS 能实现的动效**，不要为了动效写大量 Python 动画代码。如果一个效果需要 50+ 行代码，大概率不值得做。

## 交互清单（必须有）

- [ ] 所有按钮有 hover 变亮
- [ ] 所有按钮有 pressed 变暗
- [ ] 所有输入框有 focus 边框高亮
- [ ] 表格选中行有高亮
- [ ] 连接状态有颜色指示
- [ ] 空状态有占位引导
