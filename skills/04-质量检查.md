# 质量检查

## 每次改 UI 前检查

1. **布局弹性**：窗口缩放到 1280×720 和 1920×1080 都能正常显示？
2. **交互完整性**：新增的按钮/控件是否都有 hover/pressed/focus 状态？
3. **样式集中**：所有颜色/间距是否在 QSS 中，没有 inline style？
4. **无冗余**：是否有多余的 import、未使用的变量、重复的代码？

## 每次改 UI 后检查

1. 运行 `python app.py` 确认无报错
2. 检查告警列表、记录表、状态栏是否正常更新
3. 检查场景切换是否正常
4. 检查视频/图片/摄像头三种源是否都能用

## 输出格式

改动后说明：
- 改了什么
- 为什么改
- 不需要说明没改的部分
